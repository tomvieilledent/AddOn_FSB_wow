# Sonde de vérification en jeu

1. Copier l'addon, lancer le jeu, taper `/fsb sonde`.
2. Survoler un objet équipable, puis retaper `/fsb sonde` (échantillon d'un vrai objet).
3. Renvoyer la sortie du chat, ou `WTF/Account/<COMPTE>/SavedVariables/ForeverStuffBookDB.lua` (clé `probe`).

Toutes les commandes d'information (`sonde`, `etat`, `debug`, `specs`, `inconnus`, `log`, `aide`) ouvrent une fenêtre de texte : Ctrl+A puis Ctrl+C pour copier.
`/fsb log` : journal des hésitations (à envoyer chaque semaine) ; `/fsb mauvais [texte]` : signaler un mauvais verdict.
